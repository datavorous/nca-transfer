Rank 1 is the cleanest next selection target because it is highly visible and remained nearly balanced in the already tested horizontal-copy arms. Rank 2 tests learned local *relations* rather than exact repeated patch IDs. It is less isolated: both the negative high-spatial-agreement probe and negative high-cell-transition-MI probe warn that a predictive statistic need not improve English transfer. Rank 3 tests a different temporal scale but is more entangled with the high-copy policy and prior-frame recurrence.

The earlier screen used a conservative `s+1` visibility boundary. The model input starts at window offset `s`, giving **765/810** scored and visible vertical pairs per world; the old **762/810** count excluded three valid pairs. The frozen selection score and reference median use all 810 pairs and are unaffected. The [frozen protocol](VERTICAL_LAG6_FROZEN_PROTOCOL.md) records the correction.

## Reproduction and prospective test

The boundary screen is [screen_boundary_predictability.py](screen_boundary_predictability.py):

```sh
uv run --all-packages python progress/nca_search/screen_boundary_predictability.py
```

It reads every fifth of the first 5,000 accepted saved 40–50 worlds, with the original 2×2 patch grid and raster order. The boundary gain is a **diagnostic oracle** fitted separately for each world and scored only on later frames; the Transformer is never supplied its table. The high-gain share by 0.02-wide gzip bin is **.625/.586/.538/.447/.368**, so both sides occur in every sampled bin, but the crude global-median split is strongly gzip-confounded. Its sample median **0.008823605372** is provisional; freeze full-reference thresholds within each gzip bin before any sampling. Existing [vertical](VERTICAL_LAG_TARGET.md) and [temporal](TEMPORAL_TARGET.md) screens provide their definitions and reproduction scripts.

For any target, use fresh disjoint rule blocks, assign arm before measuring features, preserve original gzip sub-bin quotas, world counts, patch IDs, packed tensor contract, 19,715,325 usable NCA labels, model initialization seeds and TinyStories schedule. Compare high, low and contemporaneous unfiltered arms. Report the *achieved* feature separation and nuisance balance before running the fixed 1M-token triage; proceed to paired model seeds and full curves only through the existing gate. A language gain would initially support a **selection policy**, not a causal mechanism. In particular, the boundary oracle's positive held-out bits only show within-world predictability under its fitted table; they do not show that a fixed Transformer learns the table from its short causal windows or transfers it to English.
