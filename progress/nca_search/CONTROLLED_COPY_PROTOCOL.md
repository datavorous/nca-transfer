# Controlled horizontal-copy probe

**Status: pre-run design and read-only feasibility, not a transfer result.** Run this only after the ongoing three-block model-seed follow-up is evaluated. The question is whether selecting trajectories with more adjacent horizontal 2×2 patch copies still helps TinyStories transfer when two correlated temporal properties are balanced. Keep the original NCA rule family, 27-frame trajectory tensor, 2×2 tokenizer, packed sequence and masks, 19,975/256 train/validation worlds per arm, 19,715,325 training labels, model, and downstream schedule fixed.

## Fixed selection rule

1. Use three new, disjoint rule-stream blocks. Within each block, assign each rule seed to `high` or `low` by a recorded, domain-separated hash **before** rollout or feature measurement. Assign split by the existing `nca-split` hash. Reject any rule seed seen in the reference, prior search, another arm, or another block. Do not recycle rejected seeds.
2. Accept only gzip `[.40,.50)` and use the original per-arm train quotas `[2913,3544,4034,4559,4925]` and validation quotas `[45,42,49,57,63]` in the five consecutive .02 bins. Define copy excess exactly as in `sample_patch_replication.py`; `high` requires `>= -0.000374227071`, `low` requires `< -0.000374227071`. The cut is frozen from the original 25,000-world reference.
3. Further stratify within each gzip bin by cell lag-2 recurrence and full-trajectory consecutive-cell transition MI. Use the **reference-derived tercile cuts** lag-2 `[0.2727777778, 0.3616666667]` and MI `[0.1099513937, 0.1826968063]` bits/cell for both arms. This makes 45 joint cells. For each gzip bin, compute the reference high and low counts in each of its nine cells, set the cell weight to their minimum, normalize the nine weights, and apportion the fixed train and validation totals by largest remainder; ties go in lexicographic `(lag2_bin, MI_bin)` order. Freeze the resulting integer quota table and its SHA-256 **before generating any new rules**. Train and validation have the same within-gzip target weights but separate integer quotas. This rule uses source features only, never English outcomes.
4. In each arm, retain candidates in increasing attempt order until all `(split, gzip_bin, lag2_bin, MI_bin)` quotas fill. Set **2,000,000 attempted rules per block** as the cap. A block with an unfilled cell is incomplete; report it and do not relax bins, thresholds, hash assignment, or cap after seeing outcomes. Store rule IDs, feature scores, attempt indices, source code/config hashes, and selected tensor hashes. Use a fresh output root; never rewrite current corpora or active checkpoints.

The primary contrast is **high minus low under the same joint-cell quotas**. A gzip-only unfiltered comparator can be useful for policy value, but it is not required to answer this conditional contrast and would add a different target distribution. Do not silently compare these matched arms with the prior unmatched arms as if their source distributions were identical.

## Feasibility and audits

The existing [25,000-world read-only screen](PATCH_COPY_MECHANISM_FEASIBILITY.md) finds 10,781 balanced pairs (86.2% of each copy arm) after matching on gzip bin × lag-2 tercile × MI tercile. All 45 cells have both arms. The high-minus-low copy-excess gap remains **+0.01681**; lag-2 and MI differences shrink to **+0.00437** and **+0.00225 bits** (standardized differences **0.043** and **0.021**). Thus a copy contrast with much better balance is plausible. The saved pool alone is too small for new 19,975-world arms. Prior unadjusted replication blocks needed about 573–578k attempts for three arms; a rough acceptance calculation puts two stratified arms near 0.6M attempts, but sparse-cell fill times are unknown. The 2M cap is a ceiling, not a demonstrated guarantee.

Before any transfer comparison, require exact quotas, valid original packed dtype/layout/markers/masks, 987 usable training labels per world, disjoint rules and splits, and a successful `pack_one` spot check. Report actual full gzip CDFs, lag-2 and MI means and standardized differences, horizontal-copy excess, cell change, patch entropy and token marginals, vertical excess, lag-38/76 copy, and held-out transition-predictor gain. The **minimum manipulation check** is a positive high-minus-low horizontal-copy excess in every block and absolute standardized differences below **0.10** for lag-2 and MI; otherwise label the block a failed match before inspecting language results. Matching the two temporal scores cannot balance rule identity, patch vocabulary, or all hidden properties.

## Probe and interpretation

Use the same paired base initialization seeds and fixed 1M TinyStories checkpoint as the active replication. The primary outcome is within-block `val_loss(low) - val_loss(high)` at **1,001,472** downstream tokens, averaged across the predeclared model seeds. Secondary outcomes are the 0–1M loss AUC and, only if the primary pattern survives, the full 10M curve. The **corpus block** is the independent unit; model seeds measure sensitivity within a block. Report all block values, three-block mean/range, and exact sign count; with three blocks, even 3/3 wins give two-sided sign `p=.25` and cannot establish conventional significance.

This test is **falsified as a useful controlled copy-selection policy** if high fails to beat low at 1M in at least two of three complete blocks, or if the copy manipulation check fails. A persistent positive contrast after temporal matching weakens the specific explanations that lag-2 recurrence or transition MI alone caused the earlier gain. A vanished contrast is compatible with temporal mediation, confounding, or reduced power; it does not prove which one. Even a positive result does not prove that exact-copy attention is the transformer's learned mechanism. A stronger mechanism claim would need a rule-preserving intervention that changes copy structure without breaking the original trajectory contract.
