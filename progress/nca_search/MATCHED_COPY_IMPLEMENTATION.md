The write-once [matched_copy_freeze.json](matched_copy_freeze.json) was computed from all 25,000 saved 40–50 reference worlds. Its SHA-256 is `26e209aa1ba4f20fe14180e07d950a0cce717d4d7081b73ee94506c9b9507167`. The reference source bundle hash is `f6994c2ceb925c3372420b0ade2d266a23d97905805a8081b63abc6f621fb9f7`. Each of the 45 gzip × lag-2-tercile × MI-tercile cells has both reference arms (smallest count: 62). Cell weights are the smaller of the two reference counts within each cell. Separate train and validation integers use largest remainder within gzip, with lexicographic lag-2/MI tie breaks. The resulting per-arm gzip totals are exactly `[2913,3544,4034,4559,4925]` train and `[45,42,49,57,63]` validation. All validation cells have at least one target; train cell targets range from 110 to 991.

Blocks `g/h/i` use new JAX stream seeds `707/808/909`, respectively, domain-separated `nca-mcopy-arm` pre-feature high/low assignment and the original `nca-split` split hash. The high threshold is `>= -0.000374227071`; low is `<`. Each block has a hard cap of 2,000,000 attempts. The [sampler](sample_matched_copy.py) checks prior accepted rule IDs across the reference and search corpora, writes resume-safe compressed chunks with rule seeds, attempt IDs, raw tensors and all selection scores, and packs the same int32 `[world,1026]` token/target contract. Config, feature, generator, packing, reference and sampler hashes are recorded. The [exact audit](audit_matched_copy.py) checks the replayed rule stream, arm/split hashes, disjointness, all cell quotas, tensor contract and spot `pack_one` matches; it records full gzip quantiles and full-corpus lag-2/MI standardized differences. A separate [feature audit](screen_matched_copy_arms.py) reports sampled cell-change, entropy, token marginal, vertical copy, lag-38/76 and held-out transition-predictor gain.

Feasibility remains uncertain: the 25,000-world source pool establishes overlap but does not prove that each fresh rule stream can fill every exact cell before 2M attempts, or that the final lag-2/MI standardized differences will stay below 0.10. An incomplete block stays incomplete; the freeze and cap must not be relaxed in response to outcomes. The audit labels a failed manipulation check before any language comparison. Sample the blocks sequentially so each later block's prior-rule check sees the earlier one's selected rules.
